# All resources, one per line

SF x MIT Hack Day: Energy. Feedback or corrections (users and tool creators): https://forms.gle/k1pnQ4dtvfcGkuGK6 or email arhams@stanford.edu. Every catalog entry, grouped by type. Each line: name, creator, what it is, access, tracks (1 sites, 2 grid capacity, 3 load management, 4 aggregation), id, link.

### Data and datasets (82)

- **ACTIVSg2000: 2,000-bus synthetic grid, Texas**: Synthetic grid on the ERCOT footprint. Package includes a MATPOWER case, contingencies and a year of hourly load scenarios. - **AFDC alternative fuel station locator (US DOE)**: US public EV charging stations with location, network, connector types and power level. API through the NREL developer network (free key). (access: open; tracks: 1,3; id: afdc-stations) https://afdc.energy.gov/stations

- **Azure LLM inference traces 2023, 2024 and multimodal 2025**: Production request traces: timestamp, context tokens, generated tokens (plus images in the 2025 multimodal trace). - **Electricity Maps API**: Zone-level carbon intensity, mix, flows, load and day-ahead prices: latest, history and forecast; 5 min to hourly. Lifecycle and flow-traced by default, not marginal. 14-day trial. (access: api-key; tracks: 3,4; id: electricity-maps) https://app.electricitymaps.com/docs
- **Google Solar API**: Per-building roof area, panel layouts, sunshine hours and estimated yearly solar output. Needs a Google Cloud project with billing and an API key. (access: api-key; tracks: 1,3; id: google-solar-api) https://developers.google.com/maps/documentation/solar/overview
- **Nixtla TimeGPT SDK**: Python SDK for TimeGPT, a pre-trained time-series foundation model for forecasting and anomaly detection, including electricity. Needs a Nixtla API key. (access: api-key; tracks: 2,3; id: nixtla-timegpt) https://github.com/Nixtla/nixtla
- **NOAA Climate Data Online API v2**: Station observations and climate normals as JSON. Token header; 5 requests/s, 10,000/day; max 1,000 results per call. (access: api-key; tracks: 1,3; id: noaa-cdo-api) https://www.ncei.noaa.gov/cdo-web/webservices/v2
- **Open-Meteo weather API** by Open-Meteo (Patrick Zippenfenig): Weather forecasts and historical reanalysis by coordinate, hourly, JSON. No key for non-commercial use. (access: open; tracks: 1,3; id: open-meteo) https://open-meteo.com/
- **Overpass API (OpenStreetMap queries)** by OpenStreetMap community (Roland Olbricht): Query OpenStreetMap features by tag and area, e.g. power=substation, power=line with voltage, building footprints. No key; public endpoints are rate-limited. OSM coverage of grid assets is volunteer-mapped and uneven. (access: open; tracks: 1,2; id: overpass-api) https://wiki.openstreetmap.org/wiki/Overpass_API
- **SCE ICA ArcGIS FeatureServer**: Machine-readable SCE integration capacity layers. Tables at .../hosted/ICA_Tables/FeatureServer. (access: open; tracks: 2; id: sce-ica-featureserver) https://drpep.sce.com/arcgis_server/rest/services/hosted/ICA_Layer/FeatureServer
- **USGS Water Data APIs**: REST/OGC APIs for streamflow, groundwater, daily and continuous values at 1M+ monitoring sites. Not a water right or utility allocation. (access: open; tracks: 1; id: usgs-water-data) https://api.waterdata.usgs.gov/
