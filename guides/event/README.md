## Event statement (verbatim)

> Expect to hack on compute energy infrastructure and grid capacity forecasting.
>
> A battery chemistry that lasts 20% longer or a grid model that predicts a failure an hour earlier
> is worth real money, and a lot of it can be tested in simulation before anyone touches hardware.
> We want agents that do that testing and get better at it each run.
