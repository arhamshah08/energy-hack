# Demo ideas (demos at 18:30)

A suggested shape, not a requirement.

## 1. Structure (about 3 minutes)

| # | Part | Time | Content |
|---|---|---|---|
| 1 | Problem | 20 s | Track, the problem in one sentence, one number that shows why it matters (catalog has sourced numbers) |
| 2 | Approach | 30 s | Data, verifier, metric, loop. One diagram or one sentence each |
| 3 | Live result | 70 s | The output: map, chart, dashboard, before and after |
| 4 | Improvement | 20 s | Score across loop iterations: how the system got better each run |
| 5 | How it expands | 30 s | The next three steps (below) |
| 6 | Ask | 10 s | Data, partners or feedback you want |

## 2. How it expands

Pick the ones that fit and say them concretely.

| # | Direction | Example wording |
|---|---|---|
| 1 | Real data | "Today on synthetic or sample data; next on utility or operator data" |
| 2 | Scale | "One region today; the same loop runs on any region in the catalog" |
| 3 | Fidelity | "Next: N-1 contingencies, hourly load, a full year" |
| 4 | Across tracks | "Our sites (Track 1) feed a capacity check (Track 2), then a flexibility plan (Track 3)" |
| 5 | Coordination | "Connect to real signals: OpenADR, prices, carbon" |
| 6 | Longer loops | "More iterations, better proposer, the loop improves its own search" |
| 7 | Users | "Who would run this weekly, and what decision it changes" |

## 3. Checklist

| # | Item |
|---|---|
| 1 | Demo runs offline or with cached data |
| 2 | Backup screen recording saved |
| 3 | Screenshots of the key output |
| 4 | Iteration log or improvement chart included |
| 5 | Sources cited for any number shown (catalog id or link) |
| 6 | Synthetic data labelled as synthetic |
| 7 | Repo or link ready to share |
