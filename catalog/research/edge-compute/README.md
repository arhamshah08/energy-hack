# Edge compute deep research (7 Nov 2026)

Raw output of an AI deep research run (ChatGPT Deep Research) commissioned for this repo. Every
source in it is entered in the catalog, mostly in `catalog/edge-compute-research.yaml`, with
the report's own ID in the `ref` field. The report's categories C1 to C4 are Tracks 1 to 4 in this repo.

| # | File | Contents |
|---|---|---|
| 1 | [deep-research-report.md](deep-research-report.md) | 70-source master table (S01 to S70), public datasets table, 43-term glossary, tools and programs table, key numbers, contested claims, CSV |
| 2 | [expanded-source-notes.md](expanded-source-notes.md) | 87 source notes (R, D, S, P, N, A IDs): what each source contains, what it does not establish, verification status, corrections |

## Read with care

| # | Caveat |
|---|---|
| 1 | AI-generated. Check the primary source before citing a number |
| 2 | "Opened" in the notes means the page text was retrieved, not that data was downloaded or software run |
| 3 | Proposals, forecasts and vendor claims are labelled as such in the notes; keep that distinction |
| 4 | Program and tariff eligibility is set by the tariff and agreements, not by landing pages |
| 5 | Several URLs block automated fetches; catalog entries with `link_check: blocks-bots` open in a browser |
